# 🤖 Text-to-SQL Application

## 📌 Project Overview

This project implements a **Text-to-SQL application using the Gemini API**.

The application allows users to ask questions about a SQL database using natural language. The **Gemini API** converts the user's question into a SQL query based on the database schema, then the generated query is executed against the database using **Pandas `pd.read_sql()`**.

The project also includes a simple **Flask web application** that provides an interactive interface for entering questions, viewing the generated SQL query, and displaying the query results.

---

## 🎯 Objective

The main objective of this project is to connect **Natural Language Processing with SQL databases**, allowing users to interact with structured data without writing SQL queries manually.

The application follows this workflow:

```text
User Question
      ↓
Gemini API
      ↓
Generated SQL Query
      ↓
SQL Database
      ↓
pd.read_sql()
      ↓
DataFrame
      ↓
Display Result
```

# 🗄️ Database

The application uses the **school.DEPI** database.

The database schema is provided to Gemini as part of the prompt so that the model can generate SQL queries based on the available tables and columns.

For example:

```text
Database Schema:

Studentss:
- ID
- fname
- Courses

Convert the following question to SQL:

"Show the top 5 Students with highest Mark."
```

Providing the schema helps Gemini understand the database structure before generating the SQL query.

---

# 🔄 Application Flow

## 1️⃣ User Question

The user enters a question in natural language instead of writing SQL manually.

Example:

```text
Show the top 5 Students with highest Mark.
```

---

## 2️⃣ Gemini API

The user's question and the database schema are sent to the **Gemini API**.

Gemini analyzes the question and generates the corresponding SQL query.


## 3️⃣ SQL Execution

The generated SQL query is executed against the **school.DEPI** database.

The project uses Pandas:

```python
df = pd.read_sql(query, connection)
```

This directly loads the SQL query result into a Pandas DataFrame.

---

## 4️⃣ Display Result

The application displays:

1. The original user question.
2. The SQL query generated by Gemini.
3. The query result as a DataFrame/table.

# 🌐 Flask Web Application

# 🧠 Gemini Prompt

The Gemini prompt contains both the **database schema** and the user's question.

General prompt structure:

```text
You are a SQL assistant.

Database Schema:

[Database tables and columns]

Convert the following natural language question
into a SQL query.

Question:
[user question]

Return only the SQL query.
```

This allows Gemini to generate queries based on the actual database structure.

# ▶️ How to Run

## 1. Install Dependencies

```bash
pip install google-genai pandas pyodbc flask
```

---

## 2. Configure API Key

Store the Gemini API key as an environment variable instead of writing it directly in the source code.

```text
GEMINI_API_KEY=your_api_key
```

---

## 3. Configure Database Connection

Configure the SQL Server connection for the `Company_SD` database.

The application uses **PyODBC** to establish the database connection.

---

## 4. Run the Flask Application

```bash
python app.py
```

Then open the local Flask URL in your browser.

---

# 🔐 Security

Sensitive credentials should not be stored directly in the source code or uploaded to GitHub.

The following should be stored securely using environment variables:

* Gemini API Key
* Database username
* Database password
* Database connection information

The `.env` file should be added to `.gitignore` if it is used locally.

```text
.env
```
